# Enqui-Info
### Enquiry & Lead Management Platform

Enqui-Info is a web-based enquiry and lead management platform designed to help teams organize customer enquiries, manage follow-ups, streamline communication and monitor performance from a centralized workspace.

The application brings enquiry tracking, team coordination, WhatsApp communication and reporting together to simplify everyday enquiry management.

---

## Overview

Managing customer enquiries across multiple branches and team members can become difficult without a centralized system.

Enqui-Info aims to make this process easier by providing a structured workspace where users can manage enquiries, track their progress, schedule follow-ups and access useful business insights.

## Key Features

### 1. User Authentication & Access
- User login and registration.
- Multi-user access.
- Role-based access management.
- Organization and branch selection.

### 2. Enquiry Management
- Add and manage customer enquiries.
- Maintain customer and enquiry details.
- Track enquiry status.
- Organize enquiries in a centralized dashboard.

### 3. Follow-up Management
- Schedule customer follow-ups.
- Track pending follow-ups.
- Set follow-up reminders.
- Maintain continuity in customer communication.

### 4. WhatsApp Integration
- WhatsApp-based customer communication.
- Reusable message templates.
- Streamlined follow-up communication.

### 5. AI-Assisted Message Suggestions
- Generate message suggestions.
- Assist with customer communication.
- Reduce repetitive manual message drafting.

### 6. Dashboard & Analytics
- Centralized dashboard.
- Enquiry and follow-up overview.
- Performance tracking.
- Reports and downloadable CSV data.

## Application Workflow

1. **Authentication:** Users access the application through the login system.
2. **Dashboard:** Users get an overview of enquiry activities.
3. **Enquiry Creation:** New customer enquiries are added to the system.
4. **Enquiry Tracking:** Users manage and monitor enquiry progress.
5. **Follow-ups:** Follow-up activities are scheduled and tracked.
6. **Communication:** Users access reusable WhatsApp templates and AI-assisted suggestions.
7. **Reporting:** Users review performance and export reports.
